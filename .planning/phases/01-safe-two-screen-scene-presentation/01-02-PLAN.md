<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DM renderer → preload/main IPC | Renderer-supplied display and command data is untrusted; validate capability and sender. |
| Electron main → local backend | Loopback API commands cross a process boundary; main owns process lifecycle and origin/port handling. |
| Private backend state → public DTO → player renderer | Projection must exclude private controls, notes, and any non-public state. |
| Packaged resources → runtime | Backend binaries and scene assets must resolve only from intended local package paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02 | Information disclosure | Public DTO / player renderer | high | mitigate | Separate public projection type and renderer; tests assert only allowlisted presentation fields and black default. |
| T-01-03 | Spoofing | Preload IPC | medium | mitigate | Validate IPC sender and each narrow command payload in Electron main; no generic IPC bridge. |
| T-01-04 | Tampering | Local backend API | medium | mitigate | Bind exclusively to 127.0.0.1, use per-run capability where needed, validate commands and restrict CORS/origins. |
| T-01-05 | Denial of service | Backend readiness/process lifecycle | medium | mitigate | Bound startup/readiness wait, report actionable failure, monitor child exit, and terminate only the owned child. |
| T-01-06 | Elevation of privilege | Renderer navigation / Node integration | high | mitigate | Keep Node integration disabled, context isolation and sandbox enabled, restrict navigation/new windows, and use CSP. |
| T-01-07 | Spoofing | Display preference/topology | medium | mitigate | Re-enumerate and validate saved display IDs; disconnect/reassignment goes black and requires safe fallback/reselection. |
| T-01-SC | Tampering | npm installs | high | mitigate | Blocking-human package legitimacy verification precedes all flagged package installation. |
</threat_model>

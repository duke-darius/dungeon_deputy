## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DM renderer → authenticated loopback API | Brush/visibility commands are untrusted; preserve per-run token middleware and validate inputs. |
| Private persisted map → public presentation endpoint | Filter fog and tokens server-side; only explicit visual DTO fields cross. |
| Public API → player renderer | Strict allowlist and malformed-response blackout prevent stale/private exposure. |

| T-03-05 | Tampering | Fog stroke persistence | medium | mitigate | Validate finite map-space coordinates, radius, point/count/body bounds; serialize writes transactionally and persist before publish. |

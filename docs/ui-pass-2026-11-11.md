## Findings and iteration

1. **Fixed — Character action button used browser-default white styling.** The `New character` action now uses the brass primary treatment.
2. **Fixed — Character skill checkboxes used the native blue accent and awkward alignment.** They now use the brass accent and a clear two-column option layout; the Wizard option list mirrors the sourced class choices.
3. **Fixed — Accepted map geometry controls were unthemed and confined to a nested 160px scroller.** The controls now use the command-desk palette, expand in document flow, and retain a usable map-canvas height. E2E verifies the edited map has no horizontal page overflow.
4. **Fixed — The floating Preparation button could overlap transient map status.** It now sits in the workspace navigation row rather than overlaying content.
5. **Fixed — A paired phone kept the full join heading/status above the assigned sheet.** After pairing it now shows a compact unencrypted-HTTP warning and expiry status before the sheet. E2E asserts no horizontal overflow at 390px.
6. **Fixed — `npm run test:e2e` could use stale `renderer/dist` assets for the LAN player entry.** It now runs `vite build` before launching the hidden Electron flow.
7. **Fixed — The paired player page repeated the full join heading and took too much phone viewport.** After redemption it now shows a compact security warning and expiry status before the assigned sheet; top and action-area screenshots are captured at 390×844.
8. **Fixed — The Wizard editor offered Nature despite the backend's sourced Wizard skill list rejecting it.** Removed the unsupported choice and added a browser-level assertion.
9. **Fixed — The Preparation action wrapped awkwardly in the workspace navigation.** Shortened the visible label while retaining an explicit accessible name.
